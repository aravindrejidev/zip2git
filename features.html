Built for whole projects, not loose files

Six things Zip2Git is deliberately strict about, because a partial upload is worse than no upload.

Exact mirroring

Nothing is auto-excluded. .github/workflows, .gitignore, dotfiles and build configs all land in the commit exactly as they were in your ZIP or folder.

Atomic API engine

Every file becomes a blob, the blobs become one tree, the tree becomes one commit. Hundreds of files land in a single call sequence — never a pile of one-file commits.

Client-side privacy

Your token and your files are read directly into browser memory and sent straight to api.github.com. There's no Zip2Git server in between to store or see either one.

Dual upload modes

Drag in a .zip, or select a folder directly with webkitdirectory — including dropping a whole folder straight from your file manager.

Live progress terminal

Watch every step as it happens — unpacking, blob creation counted file by file, tree assembly, and the final commit — instead of staring at a spinner.

Works everywhere

No install, no CLI. Zip2Git runs in any modern browser — push a project from your phone on the train as easily as from a laptop.
